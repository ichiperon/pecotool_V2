# Peco 2.0.14 リリースノート

**リリース日**: 2026-06-04
**バージョン**: 2.0.14（リリース候補 / Release Candidate）

---

## はじめに

Peco 2.0.14 は、**2.x 系初のリリース候補**です。

バージョン 1.6.3 以来、操作画面の全面刷新・OCR 機能の大幅強化・ページ管理の新機能追加など、多くの改善を積み重ねてきました。今回は正式リリースの直前段階として、実際の業務環境でのご確認をお願いしています。

> **リリース候補（RC）について**
> 正式リリース前の最終確認版です。実運用で使いながら問題が見つかりましたら、ぜひフィードバックをお寄せください。皆さまの声が品質向上につながります。

---

## 主なハイライト

### 操作画面をリボン UI に刷新

画面上部の操作バーが、Excel のようなタブ＋グループ構成の「リボン UI」に生まれ変わりました。よく使う操作がグループ化されて見つけやすくなり、キーボードの **Alt キー**を使ったアクセラレータ操作にも対応しています。ウィンドウを小さくした際には自動で折りたたまれるため、どの画面サイズでも快適に使えます。

### OCR がより正確・柔軟に

| 新機能 | 内容 |
|--------|------|
| 言語選択 | 日本語・英語など複数の言語から OCR の対象言語を選択できます |
| ページ範囲を指定して OCR | `1-50`、`100`、`200-` といった形式で処理するページを絞り込めます |
| 部分的な再 OCR | 画面上で範囲を矩形で囲い、その部分だけを再度 OCR できます |
| 処理時間の表示 | OCR の残り時間と平均処理時間がリアルタイムで確認できます |
| 低信頼箇所のハイライト | OCR の精度が低い文字をハイライト表示し、確認・修正しやすくします |
| テキスト付き PDF の効率化 | すでにテキスト情報が埋め込まれた PDF は OCR をスキップして高速に取り込みます |

### ページの管理・編集

- **削除・並べ替え・回転**: ページの削除、順序の変更（ドラッグ操作）、90 / 180 / 270 度の回転が可能になりました
- **ページ抽出**: 必要なページだけを選んで別の PDF ファイルとして書き出せます

### フォルダ内の PDF をまとめて処理

フォルダを指定するだけで、フォルダ内の全 PDF に対して「OCR → エクスポート → 保存」をまとめて実行できるバッチ機能が加わりました。大量のファイルを処理する際の手間が大幅に減ります。

### 校正作業がはかどる

- **校正辞書**: よく使う置換ルールを辞書ファイルに保存・読み込みでき、一括適用が可能です
- **検索ハイライト**: PDF 上で検索にヒットした箇所をハイライト表示し、前後のヒットに素早く移動できます
- **曲線テキストの作成・分割**: 曲線に沿ったテキストブロックの作成、文字境界への自動スナップ＋プレビュー表示、連続した分割操作（Esc キーでいつでも取り消し）に対応しました

### 保存の安全性・互換性が向上

- **圧縮プリセット**: 保存時にファイルサイズと画質のバランスをプリセットから選べます
- **書き込み失敗時の案内**: 保存に失敗した場合は「別名で保存」を案内し、作業内容を失わずに対処できます
- **中断時のファイル保護**: 保存の途中で処理が止まっても、元のファイルが壊れないよう保護します
- **Acrobat 7 互換保存**: 古いバージョンの Adobe Acrobat でもテキストの位置がずれないよう、互換モードでの保存に対応しました

### 自動アップデート通知

アプリ起動時に新バージョンを確認し、通知する機能を追加しました。

> **ご注意**: 自動アップデートは、提供元による署名設定が完了してから有効になります。現時点では設定が未完了のため、通知は動作しません。

## 安定性の改善・不具合修正

実運用で見つかった問題を多数修正しています。主なものを挙げます。

- 2 ページ目以降の OCR が正しく実行されない問題
- Ctrl+0（画面フィット）が効かない場合がある問題
- サムネイル表示が乱れる場合がある問題
- ページを並べ替えた後に保存・再オープンしても順序が正しく反映されない問題
- その他、動作安定性に関わる多数の修正
