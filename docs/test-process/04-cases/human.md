## 凡例

各チェック項目の形式:

```
- [ ] **H-XX-NN** 検証内容の説明
  - 環境: 必要な環境・バージョン
  - 操作手順: 再現手順（番号付き）
  - 期待結果: 合格条件
  - 失敗時起票テンプレ: タイトルと再現情報の雛形
```

優先度: Critical（リリースブロッカー） / High（リリース前必須） / Medium（次リリース対応可） / Low（任意）

## 1. Acrobat 実機確認 — A/B テスト

### 1.1 Acrobat 7.0（レガシー互換確認）

> 背景: Acrobat 7.0 は BT...ET ブロックの word-break 処理が厳格。issue #188 の再発防止のため実機確認を必須とする。

- [ ] **H-AC-01** Acrobat 7.0 でPecoTool 保存後の PDF を開いてもエラーが表示されない
  - 環境: Adobe Acrobat 7.0 / Windows 10 または 11
  - 操作手順:
    1. PecoTool で任意の PDF を開く
    2. OCR 実行（全ページ）
    3. テキストブロックを 1 件以上編集
    4. Ctrl+S で上書き保存
    5. Acrobat 7.0 で保存済みファイルを開く
  - 期待結果: エラーダイアログが表示されない。テキストが正常に描画される。
  - 失敗時起票テンプレ:
    ```
    タイトル: [Acrobat 7.0 互換] 保存後の PDF でエラーダイアログが表示される
    再現環境: Acrobat 7.0.x / Windows xx
    再現手順: (上記手順を記載)
    期待: エラーなし
    実際: (エラーメッセージのスクリーンショット添付)
    関連 issue: #188
    ```

- [ ] **H-AC-02** Acrobat 7.0 で保存後ファイルを開いた際に「保存しますか？」ダイアログが出ない（dirty flag 抑止確認）
  - 環境: Adobe Acrobat 7.0 / Windows 10 または 11
  - 操作手順:
    1. H-AC-01 と同様に保存
    2. Acrobat 7.0 で開く
    3. Acrobat を閉じる操作（File → Close）
  - 期待結果: 「変更を保存しますか？」ダイアログが表示されない。
  - 失敗時起票テンプレ:
    ```
    タイトル: [Acrobat 7.0 互換] 保存後ファイルを開くと dirty になる
    再現環境: Acrobat 7.0.x
    期待: dirty flag なし（保存ダイアログが出ない）
    実際: 保存ダイアログが表示される
    関連 issue: #100
    ```

- [ ] **H-AC-03** Acrobat 7.0 で curve テキスト（湾曲）が文字化けしない
  - 環境: Adobe Acrobat 7.0
  - 操作手順:
    1. テキストブロックを curve モードで編集（arc 設定）
    2. Ctrl+S 保存
    3. Acrobat 7.0 で開いてテキストが正しく描画されることを確認
  - 期待結果: curve テキストが正常に表示される。文字化けなし。
  - 失敗時起票テンプレ:
    ```
    タイトル: [Acrobat 7.0 互換] curve テキストが文字化けする
    再現環境: Acrobat 7.0.x
    操作: curve モード → 保存 → Acrobat 7.0 で開く
    実際: (文字化けのスクリーンショット)
    関連 issue: #188
    ```

## 2. 大規模 PDF パフォーマンス確認

- [ ] **H-PF-01** 500 ページ PDF の初期表示が 3 秒以内に完了する
  - 環境: Windows 11 / 標準スペック PC（8GB RAM 以上推奨）
  - 操作手順:
    1. 500 ページ程度の PDF ファイルを用意（合成または実ファイル）
    2. PecoTool を起動
    3. PDF を開く操作を開始してから Canvas に 1 ページ目が表示されるまでの時間を計測
  - 期待結果: 3 秒以内に 1 ページ目が表示される。
  - 失敗時起票テンプレ:
    ```
    タイトル: [性能] 500 ページ PDF の初期表示が 3 秒を超える
    再現環境: Windows 11 / CPU: xx / RAM: xx GB
    計測値: xx 秒
    期待: 3 秒以内
    ```

- [ ] **H-PF-02** 1000 ページ PDF で任意ページへの遷移が 200ms 以内に完了する
  - 環境: Windows 11
  - 操作手順:
    1. 1000 ページ程度の PDF を開く（LRU 退避が発生する規模）
    2. サムネイルパネルで 500 ページ目、900 ページ目に順次ジャンプ
    3. ページが Canvas に描画されるまでの体感時間を確認
  - 期待結果: 各ページへの遷移が目視で 200ms 以内（もたつきなし）。
  - 失敗時起票テンプレ:
    ```
    タイトル: [性能] 1000 ページ PDF でページ遷移がもたつく
    再現: 1000 ページ PDF → ページ 500 または 900 に遷移
    症状: キャンバスの描画が明らかに遅い（体感 1 秒以上）
    ```

- [ ] **H-PF-03** 1000 ページ PDF で LRU 退避後もページデータが復元される
  - 環境: Windows 11
  - 操作手順:
    1. 1000 ページ PDF を開く
    2. 1〜50 ページを順番に閲覧（LRU 退避を誘発）
    3. 1 ページ目に戻る
    4. テキストブロックが保持されているか確認
  - 期待結果: 退避されたページのデータが再読込時に正常に復元される。
  - 失敗時起票テンプレ:
    ```
    タイトル: [LRU] 退避後ページ復元でテキストブロックが消える
    再現: 1000 ページ PDF → 多数ページ閲覧 → 1 ページ目に戻る
    症状: テキストブロックが表示されない
    ```

- [ ] **H-PF-04** 1000 ページ PDF に OCR 実行後の保存が正常に完了する
  - 環境: Windows 11
  - 操作手順:
    1. 1000 ページ PDF を開く
    2. OCR → 全ページ 実行（完了まで待機）
    3. Ctrl+S で保存
    4. 保存完了後に dirty マークが消えることを確認
  - 期待結果: 保存が完了し dirty マークが消える。保存後の PDF が Acrobat で開ける。
  - 失敗時起票テンプレ:
    ```
    タイトル: [性能] 1000 ページ OCR 後保存が失敗する
    症状: 保存エラー / dirty マークが消えない / タイムアウト
    ```

## 3. 高 DPI / 4K 環境確認

- [ ] **H-DPI-01** 4K モニタ（3840×2160）で Canvas オーバーレイがページ境界に正しく重なる
  - 環境: 4K モニタ（scaling 150% または 200% 設定） / Windows 11
  - 操作手順:
    1. ディスプレイ設定で拡大縮小を 150% または 200% に設定
    2. PecoTool を起動
    3. PDF を開いて OCR 実行
    4. OCR 結果のバウンディングボックスがテキストと一致するか確認
  - 期待結果: バウンディングボックスがテキストと正確に重なる。ズレなし。
  - 失敗時起票テンプレ:
    ```
    タイトル: [高 DPI] 4K / scaling 150% でバウンディングボックスがズレる
    再現環境: 3840×2160 / scaling 150% or 200%
    症状: BB がテキストから xpx ズレている（スクリーンショット添付）
    ```

- [ ] **H-DPI-02** 4K 環境で Canvas 描画が劣化しない（ぼけない）
  - 環境: 4K モニタ / Windows 11
  - 操作手順:
    1. 4K 環境で PDF を開く
    2. ズームイン 200% まで拡大
    3. テキストとグラフィックの描画品質を確認
  - 期待結果: 高解像度に対応した Canvas 描画でテキストがシャープに表示される。
  - 失敗時起票テンプレ:
    ```
    タイトル: [高 DPI] 4K 環境で Canvas テキストがぼける
    再現環境: 4K / scaling xx%
    症状: ズームイン時にテキストがぼやける
    ```

- [ ] **H-DPI-03** 2 モニタ環境（4K + FHD 混在）でウィンドウ移動後も描画が正常
  - 環境: 4K + FHD デュアルモニタ設定
  - 操作手順:
    1. 4K モニタで PecoTool を起動・PDF を開く
    2. ウィンドウを FHD モニタに移動
    3. Canvas 描画とオーバーレイの表示を確認
  - 期待結果: モニタ間移動後もレイアウトが崩れず描画が正常。
  - 失敗時起票テンプレ:
    ```
    タイトル: [高 DPI] モニタ間移動後に Canvas 描画が崩れる
    再現環境: 4K + FHD デュアルモニタ
    症状: (描画崩れのスクリーンショット)
    ```
