## 1. 保存の正しさ（#388 / #397・最優先ゲート①）
OCR ブロックを含む通常 PDF を開いて操作する。

- [ ] **OCR ブロック件数を目視確認**（保存前）。件数: ____
- [ ] BB を1つ動かす等の編集 → **上書き保存**（または別名保存）
- [ ] 保存した PDF を **Acrobat で開く** → **エラー/破損ダイアログが出ない**（#397: ブロック描画例外で q/Q 不均衡＝content stream 破損が出ないこと）
- [ ] Acrobat で **Ctrl+A 全選択 → コピー** → 本文が**文字化け・語の癒着なく**正しく取れる
- [ ] 保存後に再度本ツールで開き、**OCR ブロック件数が保存前と一致**（喪失ゼロ）。件数: ____
- [ ] （可能なら）**外部ツール（Acrobat の最適化/再保存）で配列 Filter 化された PDF** を開いて再保存 → **BBox メタが消えない**（#388）

## 2. 座標の正しさ（保証#4・表示）
- [ ] 表示で **BB が枠外（ページ外）に飛び出していない**
- [ ] Acrobat の **Ctrl+A 選択ハイライト位置**と、本ツールの **BB 位置がおおむね一致**（縦書き/回転ページがあれば特に）

## 3. #392（undecodable PDF の透明化）※該当 PDF があれば
「本バージョンで読み込めない OCR メタ」を持つ PDF（多重フィルタ等で decode 不能なもの）が手元にあれば確認。無ければスキップ可（エッジケース）。

- [ ] その PDF を開く → **「読み込めない OCR データがあります／編集は保存できません」警告バナーが表示される**
- [ ] 何か編集して **上書き保存** → **「保存できませんでした」警告**が出る（「保存しました」成功トーストが出ない）
- [ ] **別名保存**しても同じく**保存できない旨の警告**（成功表示で編集が消える silent loss が起きない）
- [ ] 別の**通常（decodable）PDF を開く** → 上の警告バナーが**消える**（stale 残留しない）
