# Peco 帳票ツール 統合手動確認手順（#377 段階2-5）

自動テスト（vitest / cargo test）で緑でも、canvas 描画・WindowsOCR・実 IPC・DnD は
jsdom で再現できない。出荷前に **`tauri dev` で実機確認**する（自動緑 ≠ 実機OK）。

## 前提

- Windows。`時刻と言語 > 言語と地域` で **日本語 OCR 言語パック**を導入済み。
- サンプル PDF（毎ページ同レイアウトの請求書/伝票が望ましい・複数ページ）。
- 起動: `cd apps/report-tool && npm run tauri dev`（port 1421）。
  - ランチャー経由の確認は別途: ビルド後 `Ctrl + ダブルクリック`で帳票ツール、通常起動で本体（[crates/launcher](../../crates/launcher)）。

## 最優先ゲート（リリース最低保証ライン）

- **出力の正しさ**: CSV のセル値が画面の編集結果と一致／列順がテンプレ定義順で固定。
- **表示の正しさ**: 欄の枠（BB）が PDF 上の正しい位置に描かれる（ズーム・高DPIでズレない）。

---

## 段階2: PDF 表示

- [ ] 「PDF を開く」で PDF が中央ペインに描画される
- [ ] ページ送り（< >・ページ番号入力）・ズーム（＋ −）が効く
- [ ] 描画失敗時にエラー表示 → 「別の PDF を開く」で復帰、**同一ファイル再読込でも再描画される**（空白のまま固まらない／PCT-153）

## 段階3: 欄定義ドラッグ

- [ ] 「＋ 欄を追加」で defineField モードに入る（ヒント帯表示・カーソル crosshair）
- [ ] PDF 上で矩形ドラッグ → 欄が作られ、**色塗り＋枠線＋欄名ラベル**で可視化される
- [ ] **ズーム 100% / 200% で欄枠が PDF 内容と一致**（ずれない＝表示の正しさ）
- [ ] **高DPI ディスプレイ（dpr≠1）でもずれない**
- [ ] 逆方向ドラッグ（右下→左上）でも正しい矩形になる
- [ ] 微小ドラッグ（5px未満）は欄を作らない（誤クリック破棄）
- [ ] Escape でドラッグ／モード解除
- [ ] 欄の改名・色変更・削除（右ペイン欄テンプレート）

## 段階4: 全ページ OCR（実機必須）

- [ ] OCR 実行で全ページが処理され、進捗（done/total）が出る
- [ ] キャンセルできる（途中中断・cells を確定しない）
- [ ] **原点から離れた欄（ページ中央〜右下）にも正しい値が入る**（クロップローカル座標バグの実機再現確認）
- [ ] 各欄の値が画面の欄位置と対応している
- [ ] 縦書き欄の文字結合順が妥当か
- [ ] 日本語 OCR 言語パック未導入時に、分かるエラーメッセージが出る
- [ ] temp ファイルが作られていない（OCRはbytes直渡し／PCT-118回避）
- [ ] **明細欄（isLineItem チェック済み）で、縦に複数行並ぶ品名等が 1 セルにベタ結合されず、行ごとに複数段へ分割される**
- [ ] 明細欄が複数ある場合、最初の明細欄（代表欄）の段数に他の明細欄がそろう（段数が少ない欄は空セルで埋まる）
- [ ] 単一ページ再 OCR（対象ページのみ再実行）でも明細欄が同様に複数段へ分割される

## 段階5: 横並び編集

- [ ] 1ページ=1行・各欄が横並び（横持ち CSV と一致）
- [ ] ダブルクリック / Enter・F2 でインライン編集 → Enter/blur 確定、Esc 取消
- [ ] Tab で確定して次セルへ
- [ ] セル選択 + Delete で空に／ホバー × でも空に
- [ ] **ドラッグ: 空セルへ＝値が移動**
- [ ] **ドラッグ: 埋まったセルへ＝値が入れ替わる（swap）**
- [ ] **他ページ行へはドロップできない**（他ページ行がディム表示・ページ跨ぎ禁止）
- [ ] 横スクロール時もページ列・ヘッダ行が sticky で残る
- [ ] キーボードのみで セル間移動（矢印）・編集（Enter）・削除（Delete）が完結
- [ ] cells に値がある状態で OCR 再実行 → 確認ダイアログが出る／キャンセルで実行されない
- [ ] **明細欄が複数段のページで CSV 出力すると、段数分のデータ行に展開され、固定欄（日付・合計等）は各行に複製される**（縦持ち展開）

## 用紙サイズ・向き混在の警告

- [ ] 縦横混在（または A4/A3 混在）の PDF で OCR 実行 → 完了後に「ページ N は基準ページと用紙サイズ・向きが異なります…」の警告（琥珀色）が OCR パネルに出る
- [ ] 全ページ同一レイアウトの PDF では警告が出ない

## CSV 出力

- [ ] CSV 保存でユーザー選択パスに書き出される
- [ ] **BOM 付き UTF-8**（先頭 `EF BB BF`）
- [ ] 列順がテンプレ定義順で固定（欄追加で会計ソフトの列位置がずれない）
- [ ] **編集結果（修正・削除・移動）がそのまま CSV に反映**される
- [ ] `=` `+` `-` `@` 始まりのセルが `'` 中和される（正当な負数 -50000 は中和しない／Formula Injection）

## テンプレートライブラリ（fs IPC・自動緑≠実機OK領域）

- [ ] 欄定義（複数欄・isLineItem 混在）を「現在の欄をテンプレとして保存」→ 名前入力 → 保存
- [ ] **別 PDF を開いた状態、または別セッション（アプリ再起動）で保存済みテンプレートを読込**→ 欄が同じ位置・同じ名前・同じ色・isLineItem 設定で復元される
- [ ] cells（OCR結果・手編集）がある状態でテンプレート読込 →確認ダイアログが出る → OK で cells/confidences/pageOffsets が破棄され新テンプレの欄に置き換わる（キャンセルで読込中止）
- [ ] 既存と同名で保存 → 上書き確認ダイアログ → OK で同一 id のまま上書きされる（一覧に重複行が増えない）
- [ ] 保存先ファイルが `%APPDATA%/<バンドルID>/templates/<id>.json` に実在する（エクスプローラで確認）。保存後に `<id>.json.tmp` が残っていない
- [ ] `templates/` フォルダ内の JSON ファイルを手動で破損させて（中身を不正な JSON に書き換えて）アプリを開く → 一覧は表示され、破損ファイルの行だけ「読み込めません」と表示される（一覧全体が落ちない）
- [ ] テンプレート名の改名（インライン編集・Enter確定/Escape取消）が一覧に反映される
- [ ] テンプレート削除 → 確認ダイアログ → OK で一覧から消える（キャンセルで残る）

## Undo/Redo・手修正フラグ（PCT-157 / #386）

- [ ] セル値を編集して確定 → `Ctrl+Z` で編集前の値に戻る → `Ctrl+Y`（または `Ctrl+Shift+Z`）でやり直せる
- [ ] セル削除（Delete / ×ボタン）・ドラッグ値移動・段挿入（Alt+↑↓）・段削除（Alt+Delete）・段分割（Ctrl+Enter）がそれぞれ `Ctrl+Z` 1回で戻る
- [ ] オフセット微調整（矢印キー nudge）の**ひと続きの連打が `Ctrl+Z` 1回でまとめて戻る**（1押下ずつではない・連打が履歴を押し流さない）
- [ ] `Ctrl+Z` は**ステップ③（確認）でのみ効く**（ステップ①②④では無反応 — 見えないデータが巻き戻らない）
- [ ] **セル編集中（input/textarea 内）の `Ctrl+Z` は入力欄内のテキスト取り消しになる**（グローバル undo が横取りしない）
- [ ] IME 変換中の `Ctrl+Z` で undo が誤爆しない
- [ ] OCR 再実行・テンプレート読込の後は `Ctrl+Z` しても取り込み前の状態に戻らない（履歴が境界でクリアされる）
- [ ] 手編集・削除・移動・分割したセルに **✎ バッジ＋左端の青アクセント線**が付く（ツールチップ「手修正済み」）
- [ ] 手修正済みセルを含むページを再 OCR → バッジが消える
- [ ] `Ctrl+Z` でバッジも操作前の状態に戻る
- [ ] undo/redo 後に CSV 出力 → 画面表示と CSV の値が一致する（最優先ゲート）
- [ ] 編集テーブルのツールバー **↶↷ ボタン**が履歴の有無で活性/非活性になり、クリックで undo/redo できる
- [ ] `Ctrl+Z` / `Ctrl+Y` 押下時に**画面下部にチップ**（「元に戻しました」等）が約2秒表示される。履歴が空のときは「これ以上戻せる操作はありません」
- [ ] 段挿入・段削除・段分割をしても、**触っていないセルの低信頼ハイライト（琥珀色）が消えない**（confidences リマップ）
